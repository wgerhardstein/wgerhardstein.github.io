# William Gerhardstein — Portfolio

Personal portfolio website: personal statement, skills, and projects.

**Live site:** https://wgerhardstein.github.io

Built with plain HTML, CSS, and a little vanilla JavaScript (no frameworks) and deployed with GitHub Pages from the `main` branch.

## Structure
- `index.html`: page content (About, Skills, Projects, Contact)
- `style.css`: styles, responsive layout, light/dark themes
- `script.js`: theme toggle, scroll animations, active nav highlighting
- `images/`: headshot
- `files/`: résumé PDF
